## 做了什么

1. **诊断报错链接（PR39 方向，独立实现）**  
   `diagnose/app.js` 的 `feedbackBlock` 在参考答案后增加「这道题有错？报错」。URL 仅 `template` / `title` / `question_id`，全部 `encodeURIComponent`；无 `q.id` 不渲染；`target=_blank` `rel=noopener noreferrer`，外层 `no-print`。不把答案、解析、会话、孩子档案放进 URL。测试：`tests/test_report_link.js`。

2. **首页题库异步（PR38 方向，独立实现）**  
   `assets/home.js`：topics / dependencies / standards 到位即可渲染年级卡；题库单独 `fetchJsonWithRetry`（同 URL 最多 2 次、进行中 Promise 去重）。`n-questions` 先「…」，失败或非数组为「—」，不因题库失败整页 `fail()`。学科启动时读一次，用 token 防止迟到响应串科。诊断仍保持 `await loadData()` 后再出首题；题库失败可 `questions=null`。测试：`tests/test_home.js`。

3. **六三制提示**  
   `children/index.html` 的 `#book-note` 写明六三制基准（人教/统编/教科等）及五四制尚未支持；draft 映射未启用。

4. **SW**  
   改了已缓存的 `diagnose/app.js` 与 `assets/home.js`，`sw.js` 从 **v10 → v11**。

# 中小学知识图谱（数学 + 英语）

对齐《义务教育数学课程标准（2022 年版 2025 年修订）》（教育部《中小学课程方案和课程标准日常修订版》，教材〔2025〕1 号）、《普通高中数学课程标准（2017年版2020年修订）》的**必修和选择性必修**，以及《义务教育英语课程标准（2022年版）》一级、二级和三级（7–9 年级）和《普通高中英语课程标准（2017年版2020年修订）》的必修、选择性必修。数学教材是人教版一–九、人教 A 版（2019）必修两册和选择性必修三册；英语按人教 PEP（三年级起点）三上到六下、人教版 Go for it! 七上到九年级全一册，以及人教版（2019）高中必修三册和选择性必修四册。附**自适应前置诊断**与题库。数学答错会沿先修边从高中、初中一直回溯到具体的小学知识点。英语单独成图，不和数学连边；初中英语会连回小学英语，高中英语主要连回初中英语。仓库名仍是 `cn-math-taxonomy`。

**范围：数学高中做到必修和选择性必修，并且只用人民教育出版社 A 版（2019）；英语做到三年级到高中（人教版 2019 必修三册、选择性必修四册）。这是 AI 生成的初稿。** 7.3「复数的三角表示」仍按教材选学处理，没有单独建点。定积分不在选择性必修的内容要求里，没有建点。英语不出听力和口语题。

> **状态声明：这是 AI 生成的初稿，未经任何教师审核。** 小学、初中、高中数学，以及小学、初中、高中英语都一样。
> 知识点的拆分粒度、掌握标准、诊断题答案，尤其是**先修关系（哪些是 hard、哪些是 soft，甚至某条边该不该存在）都需要一线教师审核**后才能用于教学、诊断或学习路径推荐。小学和初中数学的诊断题有自动核验，初中数学另有盲解复核，小学数学有独立程序复核；**高中题和英语题没有做盲解**，`verify` 和答案来自同一条表达式。小学册次目录、高中课标正文和高中章节目录多数不是官方逐页核对。英语课标正文、人教 PEP、Go for it! 和人教版（2019）高中英语的单元目录都没有逐页核对，标了「待核」的不要当成官方原文或页码。
>
> **册次标注：** 人教 A 版必修第二册通常在高一下学期讲授。本仓库为了把两册分成两个 `grade`，把必修第一册标成 10 / 高一，必修第二册标成 11 / 高二必修。选择性必修三册继续用 12 / 选必一、13 / 选必二、14 / 选必三，页面上不写成高三、高四。英语高中的 grade 10–12 是必修第一至三册，13–16 是选择性必修第一至四册，页面写成必修一至必修三、选必一至选必四，不写成高一到高四。这都不是教学进度的规定，待教师调整。

### dependencies.json 字段

```json
{"topicId": "A", "prerequisiteId": "B", "strength": "hard", "reason": "一句中文理由"}
```

含义：**A 依赖 B**（学 A 之前需要 B）。

- `hard`：不会 B 基本无法学 A；`soft`：会 B 对学 A 明显有帮助（类比、简化、背景），但不是硬门槛。**这个区分是 AI 的主观判断，未经审核。**
- 只保留直接先修关系，并做了传递约简：`hard` 边仅在存在另一条全 `hard` 路径时才被删除，`soft` 边在存在任何其他路径时即被删除。初中内部的边没有改写；2026-10-19 只对**新增加的**小学边、以及原来指向 `cnm_ext_*` 的边做了约简；2026-10-20 必修编译只约简当时新增的高中边，选择性必修编译只约简 `cnm_h144` 及以后的新边，小学英语编译只约简当时的 `cne_` 新边；2026-10-21 初中英语编译只约简 `cne_j` 新边，高中英语编译只约简 `cne_h` 新边，没有回头改数学边或已有小学、初中英语边。因此若看到某条边“缺失”，通常是已经能由更近的先修推出。
- 数学图的根仍是 `cnm_p001`（1到5各数的认识），`root_reason` 为「一年级认数从 1 到 5 开始，前面没有更早的小学知识点。」英语起点仍是 `cne_p001`（英语字母表）。数学和英语互不连边；初中英语可以依赖小学英语，高中英语主要依赖初中英语。先修的年级不高于后续知识点。九年级英语整册用 `semester: 全`，册次排在八年级下册之后、高中必修第一册之前。

## 诊断小工具（第四轮；第五轮改为每个知识点最多 2 题）

`diagnose/` 是一个基于上述数据的静态、可离线的诊断页面：选一个目标知识点（或整个章节），按先修关系自适应出题（第一题答对则掌握并跳过全部祖先；答错则再出一道同级或更容易的题——第二题也错才算薄弱并回溯到先修，hard 先于 soft；第二题答对标为「不稳」，不回溯），给出薄弱的根因、不稳的知识点、按年级从低到高排列的学习路径（同一年级里先修在前）、相关课标条目原文，以及一张用 Cytoscape 画的路径图（文字列表仍在）。目标可以选择小学、初中、高中必修或选择性必修知识点；答错会继续问到更早的学段；每题作答后显示解析和参考答案；进度保存在 localStorage，可导出 JSON、打印，或生成分享图。核心算法与判题在 `diagnose/engine.js`（纯函数，浏览器与 Node 通用），由 `node tests/test_engine.js` 测试。

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000/diagnose/            （演示：?target=cnm_221&demo=1）
node tests/test_engine.js                          # 引擎测试
node scripts/screenshot.js                         # 冒烟测试 + 截图（需要本机 Chrome）
```

算法说明、判题规则、URL 参数与局限见 [diagnose/README.md](diagnose/README.md)。首页、知识图谱和诊断页顶部都有同一套导航。每个知识点最多问 2 题，诊断结果只是线索。

先修：写出 211 条，传递约简后保留 **194** 条（删去 17）。选择性必修内部 148，跨模块 46（指向必修 28，初中 17，小学 1）。约简只动 `cnm_h144` 及以后的新边。导数依赖函数的单调性，瞬时变化率写明来自平均变化率的极限；空间向量直接先修平面向量和平面的基本事实；椭圆直接先修两点距离，并连到圆的方程和直线的一般式。

题库：每个点 **4** 题，共 **512**（numeric 340，choice 172；basic 与 standard 各 256）。全部带 `verify`。`second_pass_log.json` 的 E 轮写明：这些题**不是盲解**。批次在 `data/_qbatches/high_sel.json`。

直线与椭圆只做到交点个数，没有展开竞赛式的弦长。没有定积分。正态曲线的 68%、95% 写成经验规则，并标待核。

## 已知局限

- **审核缺位**：见开头状态声明；先修关系、hard/soft 强度、诊断题难度与区分度都没有经过教师或学生数据检验。
- **覆盖不均**：初中统计与概率仍是 43 个，集中在七下、八下、九下（新教材只在这三册安排统计与概率）；小学另有 9 个。九下和多册小学目录为第三方来源，非官方、待核（见上）。教材中的“阅读与思考”“数学活动”“小结”“信息技术应用”等栏目没有单独成点。
- **粒度不统一**：个别知识点（如各类应用题）按题型归并，个别（如三角形全等的各判定）拆得较细，需按实际教学再调。
- **题库很小**：小学和高中每点 4 题、初中每点 4–5 题，诊断时最多问 2 题。题与答案由 AI 生成、未经教师审核，难度与干扰项没有学生数据校准，不能代替完整测评。高中题没有盲解。
- **小学目录与课标文本**：见上文「小学教材目录」和 [docs/standards-mapping.md](docs/standards-mapping.md)。二年级下册、三至四年级上册、百分数是否单列课标条款、六年级综合与实践「确定起跑线」「节约用水」、四年级下「营养午餐」、一年级「我的教室」「数学游戏分享」是否应单列，都还待核。
- **高中是 A 版初稿**：必修和选择性必修的章节目录都来自第三方，课标正文未逐页核对。必修第二册在本仓库标成高二；选择性必修三册标成 grade 12–14，不是教学年份。立体几何证明题做成了选择题。百分位数的位置规则待核。4.4 数学归纳法在目录里带星号，是否选学待核。选必三 8.1、8.3 的节名各来源不一致。直线与椭圆只做到交点个数。没有定积分，也没有复数的三角表示。高中题没有盲解。
- **按教材顺序推断**：部分先修边（如命题、定理类内容）反映的是教材编排而非严格逻辑依赖，已尽量标为 `soft`。

## 运行校验

```bash
python3 scripts/validate.py
```

检查：JSON 合法；id 唯一；必填字段齐全；`domain`/`type`/`strength` 取值合法；每条边的两端都存在；无自环、无重复边；无环（有环时打印环路）；每个非外部知识点要么有先修边要么有 `root_reason`；没有完全孤立的节点。并打印按领域、按册次的数量以及边数、hard/soft 数。第三轮新增：`standards` 引用的课标 id 必须存在于 `data/cn-curriculum-standards.json`，`confidence` 只能是 `exact`/`inferred`，课标文件自身的 id 格式与编号连续性；并打印课标条目数、映射覆盖率；正式知识点 `standards` 为空时只打印警告（至多 30 个），设置 `STRICT_STANDARDS=1` 才视为错误。全部通过时输出 `VALIDATION PASSED` 且退出码为 0，否则输出错误并以非 0 退出。

## 打开网页

页面通过 `fetch` 读取 `data/*.json`，浏览器不允许直接用 `file://` 打开，请在本目录启动一个静态服务器：

```bash
python3 -m http.server 8000
# 首页 http://localhost:8000/
# 英语（三年级到高中） http://localhost:8000/?subject=english
# 知识图谱 http://localhost:8000/explore/
# 诊断 http://localhost:8000/diagnose/
```

三个页面共用 `assets/site.css`（柔和青绿主色，小学青绿、初中蓝、高中品红三种辅助色，跟随系统深色模式）和顶部导航：数学 / 英语、首页、知识图谱、诊断、关于（GitHub）。图形库和二维码库放在 `assets/vendor/`，页面不从外网 CDN 加载脚本、样式或字体。旧链接 `#cnm_219`、`#cnm_p001`、`#cnm_ext_002` 写在网站根路径上时，会转到知识图谱的同一哈希。`#cne_…` 转到 `explore/?subject=english#cne_…`。

**首页**（`index.html`）：一句话介绍；三步（选知识点 → 自适应答题 → 找到根因和学习路径）；四张统计卡（知识点、先修边、题目、课标条目，打开时按当前学科从数据文件计数，不写死；默认是数学）；「开始诊断」「浏览知识图谱」；数学是一至九年级入口，以及高一（必修第一册）、高二（必修第二册）、选必一、选必二、选必三（链到 `explore/?grade=`）。高中卡片不写「上 / 下」。英语首页是三年级到高中（文案写「英语：三年级到高中」），链到 `explore/?subject=english&grade=`。九年级英语卡片写「全一册」。高中英语卡片是必修一（必修第一册）到必修三，以及选必一（选择性必修第一册）到选必四，不写「高一」到「高四」，也不写「上 / 下」。数学首页仍是 14 张卡片，统计卡默认只计数学。顶部「儿童智商测试」横幅、首页卡片和诊断结果页入口不随学科改变。

**知识图谱**（`explore/`）：左侧搜索，以及学段（全部 / 小学 / 初中 / 高中）/ 年级 / 领域筛选，结果按年级·册·章折叠。英语页的学段是全部 / 小学 / 初中 / 高中，年级从三年级到九年级，再加上必修第一册到必修第三册、选择性必修第一册到第四册（不出现「高一」）。领域是语音、词汇、语法、日常表达、读写。选「小学」时清掉初中和高中，选「初中」时清掉小学和高中，选「高中」时只留必修和选择性必修。手机上目录收在顶部抽屉里。中间用 Cytoscape + dagre 只画**当前知识点的局部图**：默认向上 2 层先修（可改 1 / 2 / 3 层或全部祖先），向下 1 层。硬先修实线、软先修虚线，小学、初中、高中节点颜色不同（图例里写明），点节点即可换选中项，可缩放、拖动和「适配画面」。选「全部」时如果超过 40 个点，会先按年级收起，点「共 N 个，点此展开全部」再画每一个点，并对准当前知识点（避免缩成无法辨认的全图）。不会默认铺开全部知识点。名称过长在图上省略，悬停或点按可看全名。右侧（窄屏在图下方）是详情：名称、年级册章、领域、类型、描述、掌握标准、课标条目、样题（答案折叠）、先修列表，以及「被哪些知识点依赖」。大按钮「诊断这个知识点」进入 `diagnose/?target=<id>`；英语会带上 `subject=english`。

**诊断**（`diagnose/`）：开始页先按学段筛选并搜索，册章列表仍在，但默认折叠。数学按年级整体诊断包含一至九年级，以及高一、高二、选必一、选必二、选必三。高中不提供上下册：必修两册的范围按钮写「必修整册」，选择性必修写「整册」。URL 用 `grade=高一`、`grade=高二`、`grade=选必二`（也接受 `高一必修`、`选择性必修第二册` 这类写法）。英语是 `?subject=english`，年级从三年级到九年级，再加上必修一到必修三、选必一到选必四。整册例如 `grade=四上`、`grade=八上`、`grade=选必一`（也接受 `选择性必修第一册`、`必修第一册`）。九年级英语只有全一册，范围按钮是「全一册」，URL 用 `grade=九全`。高中英语不提供上下册：必修三册的范围按钮是「必修整册」，选择性必修是「整册」。不带 `subject` 时 `grade=必修一` 或 `选择性必修第四册` 不会选到数学。数学和英语的诊断进度分开存在本机（`cnmDiagnose.session.v2` 与 `cneDiagnose.session.v2`），题量设置仍共用。答题卡片和选项加大（触控不小于 44px）。结果页把根因、不稳和学习路径分成卡片。路径图用与知识图谱相同的 Cytoscape：小学 / 初中 / 高中分色，硬先修实线，软先修虚线，薄弱根因红框标出；文字版路径列表仍在。导出 JSON 和打印保留。结果页可以「生成分享图」：在浏览器里用 canvas 画一张 1080×1920 的竖图，写上站名、学科和诊断范围、已掌握 / 不稳 / 薄弱 / 未测、最薄弱的 2–3 章或知识点、1–2 个根因和日期。底部二维码指向 `https://math.pansgo.com/?from=share`，旁边是「扫码打开本站」，页脚注明「AI 生成初稿，仅供参考」。图上没有孩子姓名，也不涉及付费。桌面端弹层里下载，手机端长按图片保存。二维码用仓库里的 qrcode-generator 2.0.4（MIT）本地绘制。图例仍是小学、初中、高中三色，选择性必修和必修同用高中色；英语页同样保留这三色，高中英语用高中色。分享图写上学科（英语）和诊断范围（例如选必一），不把英语册次写成高一。

## 后续建议

1. 请小学、初中和高中数学教师先审先修边（尤其是 hard 边、初中→小学的 35 条、高中必修跨学段的 52 条、选择性必修跨模块的 46 条），并用教材实物或人教社官方目录核对九下、高中五册，以及上表里所有标了「非官方、待核」的小学册次（特别是二年级下册）。高中必修第二册是否应改标到高一下、选择性必修的 grade 12–14 是否要改，也请教师定。英语请同时核对 PEP、Go for it! 和高中七册的单元目录，以及高中英语指向初中的 22 条先修。

# 中小学·高中知识图谱（数学 + 语文 + 英语 + 物理）

对齐《义务教育数学课程标准（2022 年版 2025 年修订）》（教育部《中小学课程方案和课程标准日常修订版》，教材〔2025〕1 号）、《普通高中数学课程标准（2017年版2025年修订）》的**必修和选择性必修**，以及《义务教育英语课程标准（2022年版）》一级、二级和三级（7–9 年级）和《普通高中英语课程标准（2017年版2025年修订）》的必修、选择性必修。数学教材是人教版一–九、人教 A 版（2019）必修两册和选择性必修三册；英语按人教 PEP（三年级起点，根据2022年版课程标准修订的新版）三上到六上（五下、六下新版未上线，暂按旧版）、人教版 Go for it! 新版七上到九上（九下新版未上线，暂按旧版九年级全一册第 9–14 单元等），以及人教版（2019）高中必修三册和选择性必修四册。初中物理按人教版新版（根据2022年版课程标准修订）八年级上册、八年级下册、九年级全一册，对齐《义务教育物理课程标准（2022年版2025年修订）》；高中物理按人教版（2019年审定）必修第一至三册和选择性必修第一至三册，对齐《普通高中物理课程标准（2017年版2020年修订）》。附**自适应前置诊断**与题库。数学答错会沿先修边从高中、初中一直回溯到具体的小学知识点。英语单独成图，不和数学连边；初中英语会连回小学英语，高中英语主要连回初中英语。物理也单独成图，用到的数学写在知识点的 `mathLinks` 字段里，不算先修边。仓库名仍是 `cn-math-taxonomy`。

**范围：数学高中做到必修和选择性必修，并且只用人民教育出版社 A 版（2019）；英语做到三年级到高中（人教版 2019 必修三册、选择性必修四册）。这是 AI 生成的初稿。** 7.3「复数的三角表示」仍按教材选学处理，没有单独建点。定积分不在选择性必修的内容要求里，没有建点。英语不出听力和口语题。

### topics.json 字段

|---|---|

| `chapter` | 人教版章节。初中如 `七上 第一章 有理数 1.2.1`；小学如 `一年级上册 第1单元 5以内数的认识和加、减法`；高中必修如 `高一 第一章 集合与常用逻辑用语 1.1`（必修第一册）、`高二 第六章 平面向量及其应用 6.1`（必修第二册）。选择性必修如 `选必一 第一章 空间向量与立体几何 1.1`、`选必二 第五章 一元函数的导数及其应用 5.1`、`选必三 第六章 计数原理 6.1`。建模与探究不带「第×章」：`高一 数学建模 建立函数模型`、`选必三 数学探究 杨辉三角的性质与应用`、`选必三 数学建模 建立统计模型进行预测`。高中 `grade` 为 10–14，`semester` 都写「上」（不拆上下册）。12、13、14 只表示选择性必修三册，不是高三、高四 |

| `external` | `false` |

### dependencies.json 字段

```json

```

- `hard`：不会 B 基本无法学 A；`soft`：会 B 对学 A 明显有帮助（类比、简化、背景），但不是硬门槛。**这个区分是 AI 的主观判断，未经审核。**

## 诊断小工具（第四轮；第五轮改为每个知识点最多 2 题）

`diagnose/` 是一个基于上述数据的静态、可离线的诊断页面：选一个目标知识点（或整个章节），按先修关系自适应出题（同一知识点连续答对默认 3 题才掌握并跳过全部祖先，开始页可选 2/3/5；答错则再出一道同级或更容易的确认题——确认题也错才算薄弱并回溯到先修，hard 先于 soft；确认题答对标为「不稳」，不回溯），给出薄弱的根因、不稳的知识点、按年级从低到高排列的学习路径（同一年级里先修在前）、相关课标条目原文，以及一张用 Cytoscape 画的路径图（文字列表仍在）。目标可以选择小学、初中、高中必修或选择性必修知识点；答错会继续问到更早的学段；每题作答后显示解析和参考答案；进度保存在 localStorage，可导出 JSON、打印，或生成分享图。核心算法与判题在 `diagnose/engine.js`（纯函数，浏览器与 Node 通用），由 `node tests/test_engine.js` 测试。

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000/diagnose/            （演示：?target=cnm_221&demo=1）
node tests/test_engine.js                          # 引擎测试
node scripts/screenshot.js                         # 冒烟测试 + 截图（需要本机 Chrome）
```

算法说明、判题规则、URL 参数与局限见 [diagnose/README.md](diagnose/README.md)。首页、知识图谱和诊断页顶部都有同一套导航。每个知识点最多问 2 题，诊断结果只是线索。

## 已知局限

- **审核缺位**：见开头状态声明；先修关系、hard/soft 强度、诊断题难度与区分度都没有经过教师或学生数据检验。
- **覆盖不均**：初中统计与概率仍是 43 个，集中在七下、八下、九下（新教材只在这三册安排统计与概率）；小学另有 9 个。九下和多册小学目录为第三方来源，非官方、待核（见上）。教材中的“阅读与思考”“数学活动”“小结”“信息技术应用”等栏目没有单独成点。
- **粒度不统一**：个别知识点（如各类应用题）按题型归并，个别（如三角形全等的各判定）拆得较细，需按实际教学再调。
- **题库很小**：小学和高中每点 4 题、初中每点 4–5 题，诊断时最多问 2 题。题与答案由 AI 生成、未经教师审核，难度与干扰项没有学生数据校准，不能代替完整测评。高中题没有盲解。
- **小学目录与课标文本**：见上文「小学教材目录」和 [docs/standards-mapping.md](docs/standards-mapping.md)。二年级下册、三至四年级上册、百分数是否单列课标条款、六年级综合与实践「确定起跑线」「节约用水」、四年级下「营养午餐」、一年级「我的教室」「数学游戏分享」是否应单列，都还待核。
- **高中是 A 版初稿**：章节目录已于 2026-10-22 对照国家中小学智慧教育平台人教 A 版五册目录页预览核对（必修第一册 6e764703、必修第二册 d296fc79、选择性必修第一册 d0fd2c1f、第二册 99c1fb5b、第三册 ffaba6c3；平台上只有 2019 年版这一套，本册导引写明依据 2017 年版课标，没有更新的修订版），章、节编号一致；必修第一册 `cnm_h038` 由 3.3 改挂 3.4「函数的应用（一）」。8.1 成对数据的统计相关性、8.2 一元线性回归模型及其应用、8.3 列联表与独立性检验以目录页为准；*4.4 数学归纳法、*7.3 复数的三角表示在目录里带星号。课标正文未逐页核对。必修第二册在本仓库标成高二；选择性必修三册标成 grade 12–14，不是教学年份。立体几何证明题做成了选择题。百分位数的位置规则待核。4.4 数学归纳法在目录里带星号，是否选学待核。选必三 8.1、8.3 的节名各来源不一致。直线与椭圆只做到交点个数。没有定积分，也没有复数的三角表示。高中题没有盲解。

**首页**（`index.html`）：一句话介绍；三步（选知识点 → 自适应答题 → 找到根因和学习路径）；四张统计卡（知识点、先修边、题目、课标条目，打开时按当前学科从数据文件计数，不写死；默认是数学）；「开始诊断」「浏览知识图谱」；数学是一至九年级入口，以及高一（必修第一册）、高二（必修第二册）、选必一、选必二、选必三（链到 `explore/?grade=`）。高中卡片不写「上 / 下」。英语首页是三年级到高中（文案写「英语：三年级到高中」），链到 `explore/?subject=english&grade=`。九年级英语卡片写「全一册」。高中英语卡片是必修一（必修第一册）到必修三，以及选必一（选择性必修第一册）到选必四，不写「高一」到「高四」，也不写「上 / 下」。数学首页仍是 14 张卡片，统计卡默认只计数学。顶部「儿童智商测试」横幅、首页卡片和诊断结果页入口不随学科改变。

**知识图谱**（`explore/`）：左侧搜索，以及学段（全部 / 小学 / 初中 / 高中）/ 年级 / 领域筛选，结果按年级·册·章折叠。英语页的学段是全部 / 小学 / 初中 / 高中，年级从三年级到九年级，再加上必修第一册到必修第三册、选择性必修第一册到第四册（不出现「高一」）。领域是语音、词汇、语法、日常表达、读写。选「小学」时清掉初中和高中，选「初中」时清掉小学和高中，选「高中」时只留必修和选择性必修。手机上目录收在顶部抽屉里。中间用 Cytoscape + dagre 只画**当前知识点的局部图**：默认向上 2 层先修（可改 1 / 2 / 3 层或全部祖先），向下 1 层。硬先修实线、软先修虚线，小学、初中、高中节点颜色不同（图例里写明），点节点即可换选中项，可缩放、拖动和「适配画面」。选「全部」时如果超过 40 个点，会先按年级收起，点「共 N 个，点此展开全部」再画每一个点，并对准当前知识点（避免缩成无法辨认的全图）。不会默认铺开全部知识点。名称过长在图上省略，悬停或点按可看全名。右侧（窄屏在图下方）是详情：名称、年级册章、领域、类型、描述、掌握标准、课标条目、样题（答案折叠）、先修列表，以及「被哪些知识点依赖」。大按钮「诊断这个知识点」进入 `diagnose/?target=<id>`；英语会带上 `subject=english`。

**诊断**（`diagnose/`）：开始页先按学段筛选并搜索，册章列表仍在，但默认折叠。数学按年级整体诊断包含一至九年级，以及高一、高二、选必一、选必二、选必三。高中不提供上下册：必修两册的范围按钮写「必修整册」，选择性必修写「整册」。URL 用 `grade=高一`、`grade=高二`、`grade=选必二`（也接受 `高一必修`、`选择性必修第二册` 这类写法）。英语是 `?subject=english`，年级从三年级到九年级，再加上必修一到必修三、选必一到选必四。整册例如 `grade=四上`、`grade=八上`、`grade=选必一`（也接受 `选择性必修第一册`、`必修第一册`）。九年级英语只有全一册，范围按钮是「全一册」，URL 用 `grade=九全`。高中英语不提供上下册：必修三册的范围按钮是「必修整册」，选择性必修是「整册」。不带 `subject` 时 `grade=必修一` 或 `选择性必修第四册` 不会选到数学。数学和英语的诊断进度分开存在本机（`cnmDiagnose.session.v2` 与 `cneDiagnose.session.v2`），题量设置仍共用。答题卡片和选项加大（触控不小于 44px）。结果页把根因、不稳和学习路径分成卡片。路径图用与知识图谱相同的 Cytoscape：小学 / 初中 / 高中分色，硬先修实线，软先修虚线，薄弱根因红框标出；文字版路径列表仍在。导出 JSON 和打印保留。结果页可以「生成分享图」：在浏览器里用 canvas 画一张 1080×1920 的竖图，写上站名、学科和诊断范围、已掌握 / 不稳 / 薄弱 / 未测、最薄弱的 2–3 章或知识点、1–2 个根因和日期。底部二维码指向 `https://math.pansgo.com/?from=share`，旁边是「扫码打开本站」。图上没有孩子姓名，也不涉及付费。桌面端弹层里下载，手机端长按图片保存。二维码用仓库里的 qrcode-generator 2.0.4（MIT）本地绘制。图例仍是小学、初中、高中三色，选择性必修和必修同用高中色；英语页同样保留这三色，高中英语用高中色。分享图写上学科（英语）和诊断范围（例如选必一），不把英语册次写成高一。

## 后续建议

1. 请小学、初中和高中数学教师先审先修边（尤其是 hard 边、初中→小学的 45 条、高中必修跨学段的 54 条、选择性必修跨模块的 46 条），并用教材实物或人教社官方目录核对九下、高中五册，以及上表里所有标了「非官方、待核」的小学册次（特别是二年级下册）。高中必修第二册是否应改标到高一下、选择性必修的 grade 12–14 是否要改，也请教师定。英语请同时核对 PEP、Go for it! 和高中七册的单元目录，以及高中英语指向初中的 22 条先修。
2. 请课程专家审核 `standards` 映射（尤其 inferred，以及第一至三学段尚未与教育部 PDF 逐页核对的条文），并考虑为仍无对应知识点的课标条款补点。
3. 用真实学生答题数据校准诊断题与先修强度。

```bash
./scripts/deploy-cf.sh
```
